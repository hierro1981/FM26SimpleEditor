# Application icon

Original artwork generated with the built-in ImageGen tool for FM26 Simple Editor. App.png is the 256×256 PNG; App.ico contains 16, 24, 32, 48, 64, 128 and 256 px frames. The icon is embedded in the executable and as a managed resource for the main and startup windows. No external icon file is required at runtime.

Prompt: One original Windows application icon for a football player save editor: deep navy rounded-square badge, white soccer ball and bold mint-green editing pencil. Clean geometric shapes, high contrast, readable at 16×16 and 32×32, transparent outside the silhouette; no text, numbers, official Football Manager logos or third-party trademarks.
