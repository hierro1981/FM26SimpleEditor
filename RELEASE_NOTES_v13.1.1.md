## Italiano

La v13.1.1 include tutte le novità della v13:
- Selettore Italiano / English, traduzione dell’interfaccia tramite risorse e preferenza salvata accanto all’eseguibile.
- Finestra Informazioni con versione e verifica delle release più recenti su GitHub.
- Pulsanti per copiare nome, ID pubblico e ID interno del giocatore.
- Storico con mesi ricostruiti quando disponibili, selezione iniziale degli attributi per posizione e preset.
- Tooltip dello storico con attributo, valore e data nei colori del grafico; delta colorati per miglioramenti e peggioramenti.
- Caricamento del giocatore con percentuale, fasi e contatori disponibili.
- README italiano e inglese con badge dei download e note delle versioni dalla più recente alla più vecchia.

**Windows x64:** estrai lo ZIP completo e avvia FM26SimpleEditor.exe. Richiede **.NET 8 Desktop Runtime x64**, escluso dal pacchetto. Python e le dipendenze vengono verificati all’avvio. Lo ZIP include il codice sorgente corrispondente.

## English

Version 13.1.1 includes all v13 changes:
- Italian / English selector, resource-based interface translation and language preference saved beside the executable.
- About dialog with application version and checks for newer GitHub releases.
- Buttons to copy the player name, public ID and internal ID.
- Attribute history with reconstructed months where available, position-based initial selection and presets.
- History tooltips showing attribute, value and date in chart colours; coloured improvement and deterioration deltas.
- Player loading with percentage, processing phases and available counters.
- Italian and English READMEs with total download badges and newest-first version notes.

**Windows x64:** extract the entire ZIP and run FM26SimpleEditor.exe. Requires **.NET 8 Desktop Runtime x64**, which is not bundled. Python and dependencies are checked at startup. Corresponding source is included in the ZIP.
