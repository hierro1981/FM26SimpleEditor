Questions and answers

Can I edit FM27 saves?

Yes. Version 16.2.0 supports FM27 build 27.0.0+2493426. Player editing and in-game loading of a modified copy have been verified. Other readable builds remain view-only.

Why is my save view-only after a game update?

The format may change between builds. The editor checks the build when opening and before writing; new FM27 versions are not automatically enabled. Check releases for a compatible update.

It is still called FM26 Simple Editor. Does it work with FM27?

Yes. The project keeps its original name, repository and executable, while version 16.2.0 adds the stated FM27 build. You do not need a separate program.

Is it free?

Yes. The project is free and its source code is public on GitHub. The licence and its conditions are included in the repository and distribution packages.

Do I need the official editor or Visual Studio?

Neither Visual Studio nor the official Football Manager editor is needed to use this program. You need Windows x64, .NET 8 Desktop Runtime x64, Python and the dependencies described in the guide.

Why does it need Python?

Reading and writing the save format uses a Python backend; the C# application provides the interface. The editor checks its environment at startup and helps prepare missing components.

Why is Technique on a different scale from the game?

Editing displays the raw 1–100 scale. In-game preview converts attributes to the visible 1–20 scale. Use the preview when comparing the presentation with Football Manager.

Can I create players, transfer them or edit staff?

These features are not available. The editor changes supported data for existing players; staff and tactics are viewable. It does not attach to the running game or edit its memory.

Are staff stars and interest the official game ratings?

No. They are editor estimates based on readable data and the criteria explained in the interface. They do not guarantee performance, development or contract acceptance. Future estimates do not guarantee reaching PA.

Does the save contain a complete CA history?

CA over time comes from comparing saves from the same career at their actual dates. Some files also contain internal attribute samples; those are not a complete historical CA series with exact dates.

Why are some data or tactics unavailable?

Availability depends on the build and the records present. Missing data and unknown roles are not replaced with invented values. My squad uses the first identified human manager.

How can I report a useful bug?

Open an issue in the repository with the editor version, game build, steps to reproduce and error text. For incorrect readings, comparison with a game screenshot helps verify the data. Issues are public.
