Setup or portable ZIP?

Setup: guided installation

Download the Setup-win-x64.exe asset from the release and follow the wizard. You can choose prerequisite preparation; additional downloads and installations require your consent.

ZIP: extract and run

Download FM26SimpleEditor-win-x64.zip, extract all files into a folder and run FM26SimpleEditor.exe. Keep the DLLs, Python files and package folders together. The source-code ZIP is not the executable package.

Open downloads ↗ · Official .NET 8 downloads ↗

For manual .NET installation, choose .NET Desktop Runtime → Windows → x64.

First launch

The editor checks Python and its required libraries. It offers Python installation when missing and prepares missing dependencies. If preparation fails, retry from the same window.

Python reads and writes the save format; the Windows interface is written in C#. Normal use does not require running Python commands.

Your first edit, step by step

  1. Prepare your saveKeep a working original copy and use the local career file.
  2. Open it in the editorChoose Open save. Check the identified game and build in the top bar.
  3. Find a playerSearch by name, club or ID. Open the player and select Edit.
  4. Review the valuesChange supported fields and check the 1–20 preview. Raw editing attributes use a 1–100 scale.
  5. Save changesUse the button next to Open save and choose a destination for the new copy.
  6. Check in the gameLoad the modified copy in Football Manager and review the data. Keep the original as your reference.

Language, updates and help

Options contains language and the number of position/tactic candidates. Your choices are remembered. About shows the version and lets you check for new releases.

To update a portable installation, extract the complete new package; avoid mixing files from different versions. If a new FM27 build opens in view-only mode, check whether a newer editor release supports it.

For reading or startup problems, visit the FAQ or open a GitHub issue with the editor version, game build and error text. GitHub issues are public: leave out anything you do not want to share.
