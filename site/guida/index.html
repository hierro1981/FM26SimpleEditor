Setup o ZIP portatile?

Setup: installazione guidata

Scarica il file Setup-win-x64.exe dagli allegati della release ed esegui la procedura guidata. Puoi scegliere la preparazione dei componenti necessari; eventuali download e installazioni aggiuntive richiedono il tuo consenso.

ZIP: estrai e avvia

Scarica FM26SimpleEditor-win-x64.zip, estrai tutti i file in una cartella e avvia FM26SimpleEditor.exe. Mantieni insieme DLL, file Python e cartelle del pacchetto. Non usare lo ZIP del codice sorgente come pacchetto eseguibile.

Apri la pagina dei download ↗ · .NET 8 ufficiale ↗

Per installare .NET manualmente scegli .NET Desktop Runtime → Windows → x64.

Al primo avvio

L’editor verifica Python e le librerie richieste. Se Python manca, propone l’installazione; se mancano dipendenze, prepara l’ambiente. In caso di errore puoi riprovare dalla stessa finestra.

Python serve alla lettura e scrittura del formato dei salvataggi; l’interfaccia è un’applicazione Windows in C#. Non occorre eseguire comandi Python per il normale utilizzo.

La prima modifica, passo per passo

  1. Prepara il salvataggioConserva una copia originale funzionante e usa il file locale della carriera.
  2. Apri nell’editorPremi Apri salvataggio. Controlla il gioco e la build riconosciuti nella barra superiore.
  3. Trova un giocatoreCerca per nome, squadra o ID. Apri il giocatore e passa a Modifica.
  4. Controlla i valoriModifica i campi supportati e consulta l’anteprima 1–20. La scala grezza degli attributi in modifica è 1–100.
  5. Salva le modificheUsa il pulsante vicino ad Apri salvataggio e scegli la destinazione della nuova copia.
  6. Verifica nel giocoCarica la copia modificata in Football Manager e controlla i dati. Il file originale resta il tuo riferimento.

Lingua, aggiornamenti e aiuto

Le Opzioni raccolgono lingua e numero di candidati per posizione o tattica. La scelta viene ricordata ai successivi avvii. La finestra Informazioni mostra la versione e consente di verificare nuove release.

Per aggiornare lo ZIP, estrai il nuovo pacchetto completo: evita di mescolare file di versioni diverse. Se una nuova build FM27 viene aperta in sola lettura, verifica se è disponibile un aggiornamento dell’editor che la supporti.

Per un problema di lettura o avvio, consulta le domande frequenti o apri una segnalazione su GitHub indicando versione dell’editor, build del gioco e testo dell’errore. Le segnalazioni GitHub sono pubbliche: evita di includere dati che non vuoi condividere.
